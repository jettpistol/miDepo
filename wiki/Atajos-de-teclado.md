# Atajos de teclado

En la computadora, las tareas del depósito se hacen sin mouse. Apretá **F1** en cualquier pantalla y miDepo muestra los atajos que sirven ahí.

## Ir a otra pantalla

Mantené **Alt** y apretá un número.

| Atajo | Pantalla |
|---|---|
| Alt + 0 | Inicio |
| Alt + 1 | Recepción |
| Alt + 2 | Reposición |
| Alt + 3 | Picking |
| Alt + 4 | Empaque |
| Alt + 5 | Devoluciones |
| Alt + 6 | Conteos |
| Alt + 7 | Mover |
| Alt + 8 | Stock |

## Dentro de una pantalla

Cada tecla hace lo mismo en todas las pantallas que la usan.

| Tecla | Qué hace | Ejemplos |
|---|---|---|
| **F1** | Muestra los atajos de esta pantalla | |
| **F2** | El botón principal | Confirmar, Sumar, Guardar, Mover; Preparar el pedido; abrir el primero de la lista |
| **F3** | Volver a la lista | De un pedido a Picking |
| **F4** | Poner la cantidad sugerida | "Todas: 60" |
| **F6** | Cambiar el estado del libro | En una devolución: Vendible → Dañado → Saldo |
| **F7** | Poner el estante sugerido | "Está en A-01-1", "Ya hay en A-03-2" |
| **F8** | La otra acción de la pantalla | Picking: No está en el estante · Empaque: Cerrar caja · Conteo: Terminé esta ubicación · Reposición: cambiar entre Recepción y Devoluciones |
| **F9** | Terminar la tarea | Cerrar recepción · Cerrar devolución · Terminar pedido · Aprobar el conteo |
| **F10** | Nueva | Nueva recepción, Nueva devolución |
| **Esc** | Borrar lo escaneado y empezar de nuevo | |

Si una tecla no hace nada en una pantalla, es porque ahí no tiene uso.

> Las acciones que piden confirmación (cerrar una recepción, no está en el estante…) la piden igual con el atajo: apretá **Enter** para aceptar o **Esc** para cancelar.

## Un ejemplo: preparar un pedido

1. **Alt + 3** abre Picking.
2. **F2** toma el pedido más antiguo (o sigue con el tuyo).
3. Escaneá el estante y el libro: con lector se confirma solo. Si no, **F2**.
4. Si el libro no está, **F8**.
5. Al terminar, **F2** lleva a Empaque.

## Teclas que miDepo no usa

**F5** (recargar la página), **F11** (pantalla completa) y **F12** siguen siendo del navegador.
